# SuperShot 0.2 verification

> The interface was redesigned after this report. The screenshots in this folder show the previous UI; current renders are in `docs/previews/`. The redesign has been checked only through offscreen renders and the background test suite, not in a live window.

Environment: Apple Silicon, macOS 27.2 (26B5101f), Swift 6.4, Command Line Tools with the macOS 27.0 SDK. Deployment target: macOS 26. This checkout has no Git repository, so no commit or PR was created.

## Automated checks

The reproducible commands are `scripts/test.sh`, `scripts/bundle.sh`, and `scripts/benchmark.sh`. Final logs live in ignored `.build/final-tests.log`, `.build/bundle.log`, and `.build/benchmark.log`.

Final result after all code and live-check fixes: **49 tests passed across 11 test targets, zero failures**, exit status 0. `CONFIGURATION=release scripts/bundle.sh` completed successfully. Strict `codesign` verification passed; the designated requirement remains `dev.desenyon.SuperShot` with certificate leaf `e913487d4ca36437c0e82782ae7f60c12d000be3`. The final bundle is `dist/SuperShot.app`, version 0.2.0. Appearance was restored to Dark after the light-mode checks.

Coverage includes document validation and round trips; undo and autosave; rendered pixel probes and an independently drawn golden PNG; clipped and rotated effects; decode-cache isolation; export naming and paired-sidecar collisions; corrupt preference recovery; hotkey conflicts; permission transitions; exact selection coordinates; odd-pixel Retina stitching; real Vision text/QR recognition; local AI extraction; and library restart, OCR search, retention, and edit preservation.

Tests were added after implementation in the final audit pass as requested. They are not represented as a test-first red/green cycle. The new small-text OCR fixture initially failed only because fast Vision normalized `SuperShot` to `Supershot`; its assertion now checks the complete phrase case-insensitively.

The toolchain emits linker warnings for absent Command Line Tools Developer library/framework search paths. These are distinct from test failures. The test wrapper explicitly loads Apple's bundled Testing macro plugin.

## Audit fixes

| Finding | Implemented correction | Evidence |
|---|---|---|
| Reopening a capture could replace edits with its original | Reuse the existing editor by document ID or load its saved project | Library edit-preservation tests and live reopen after restart |
| Different image formats could collide with a sidecar basename | Reserve the image/project pair together; preserve unrelated sidecars | Export collision tests |
| Corrupt geometry/preferences could overflow or allocate huge images | Validate finite values, dimensions, derived output size, scale, and counters; preserve corrupt preference backup | Document/settings tests |
| 100% zoom and color sampling could use a reduced preview | Render full source resolution at 100%+; sample a full-resolution render | Editor resolution test |
| Rotated/clipped effects could sample the wrong pixels | Clip transformed regions and composite the full snapshot in device coordinates | Renderer effect tests |
| Edits left outdated redaction proposals | Clear proposals, generated descriptions, and stale success messages on edits, undo, and redo | Editor test and live recognition-invalidated/undo flow |
| Downsampled overlap estimates lost odd Retina offsets | Refine the best candidate at source height | Exact odd-offset stitch test |
| An old scroll task could clear a new session | Session-identity check before clearing task state | Code audit; live three-frame capture and Finish |
| Quit could interrupt debounced edits or the initial original save | Flush editors and await tracked save tasks before termination | Autosave test and live immediate-quit/relaunch recovery |
| Fast OCR ignored normal text on a large screen | Use an eight-source-pixel minimum text-height threshold | Real Vision small-text regression and 5K benchmark |
| Every annotation redraw decoded the original again | Shared thread-safe decoded-image cache with a 128 MiB eviction budget | Pixel-isolation test and before/after benchmark |

Live-check corrections also add native Edit-menu shortcuts, whitespace-tolerant OCR search, accessible library thumbnail labels, a pin context menu and close handling, and recognition of pins as visible app surfaces. The phrase `Reference 55534` successfully finds OCR text containing `Ref erence` and a line break. Additional corrections cover stale copy completion ordering, unavailable AI handling, concurrent-edit AI result rejection, original image orientation, automatic-backdrop output consistency, shortcut recorder cleanup, bounded pixel-grid work, and profile normalization.

## Measured performance

Synthetic release benchmark, 5120×2880 original with 200 rectangle/arrow layers, five render samples per size. There are no blur or magnifier layers in this workload. Timings cover the renderer call, not AppKit presentation, event delivery, or a complete frame.

| Workload | Before fixes | After fixes |
|---|---|---|
| 2200-pixel preview, warm renders | 50.7–51.3 ms | 8.55–8.84 ms |
| Full 5120-pixel render, warm | 37.6–37.8 ms | 8.25–9.05 ms |
| First preview render | 56.4 ms | 51.3 ms |
| First full render after preview warms the cache | 38.4 ms | 16.6 ms |
| Fast OCR, 24 small text rows | 0 recognized | 24 recognized, 169.6–180.6 ms |
| Accurate OCR, 24 rows, after model compilation | — | 24 recognized, 190.4–205.1 ms |

The initial run took 3.9 seconds for fast analysis and 27.5 seconds for accurate analysis; a process sample showed Apple Neural Engine model compilation. Later timings benefit from that system cache. Do not promise a sub-300 ms first use, universal 60 fps, or measured hotkey-to-overlay and capture-to-thumbnail budgets from these results. Earlier overlay observations were approximately 122 ms cold and 65–68 ms warm, before the final changes; those are historical diagnostics, not a final timing gate.

## Boundaries still requiring work

- Multi-display configurations, complete VoiceOver navigation, login-item registration, permission revocation during capture, pin click-through/opacity/resize, and auto-scroll Accessibility consent remain unverified. Pin creation, its native menu, keyboard closing, manual scrolling, and history recovery were checked live.
- End-to-end performance budgets, effect-heavy 200-layer canvases, memory pressure, long scrolling sessions, and macOS 26 behavior require separate measurements.
- Advanced specification details still absent include configurable area modifier behavior, per-format quality values, arbitrary custom ratios, zoom-to-selection, all contextual tool-style previews, richer capture-position metadata, thumbnail swipe/pin controls, and native Shortcuts discovery with this toolchain.
- Cloud providers and downloadable models were not added: AGENTS.md requires approval for application network calls/dependencies. Local patch erase and image resampling are not generative inpainting or learned upscaling. Apple Intelligence and translation depend on the Mac's available models/languages.
- The app is locally signed, not Developer ID signed or notarized. Periodic macOS capture-permission reprompt timing was not established.

The implementation is a working local development build, not a claim that every milestone in the product specification has passed its acceptance gate.
