# SuperShot 0.1.0 verification

Date: 2026-11-18. Version 0.1.0, build 7. Branch `feature/ask-and-ui-refresh`.

All checks ran offscreen on the development Mac while it was in use: no app was launched, no window was shown, no input was posted, and the shared clipboard was not touched. The running local app was not replaced.

## Automated tests

`scripts/test-background.sh`: **119 tests across 11 targets passed** (0.0.1 had 76).

New coverage in this release:

| Area | What is tested |
|---|---|
| Ask backends (`AITests`) | Codex JSON-RPC handshake, streamed deltas, declined approval requests, rate-limit mapping, API-key accounts treated as signed out, version gating, CLI search order, Claude stream-json parsing including partial deltas and error results, temporary-folder permissions and cleanup, image downscaling, and one end-to-end test per backend against a fake CLI executable |
| Ask model (`EditorTests`) | Consent gating, rendered region cropping, redaction before upload, streaming accumulation, late events after Stop, retries, provider switching after a usage limit, the transcript hook, restored conversations carried into the next thread, and region picking on a detached canvas |
| Area bar (`CaptureTests`) | Action order and labels from preferences; Capture always present |
| Settings (`SettingsTests`) | Old preferences decode with defaults, invalid customization ids are dropped, Capture stays first, reorder and visibility helpers, sign-in polling and cancellation |
| History (`LibraryTests`) | Conversations kept only for captures in History, stored with 0600 permissions, searchable, preserved when the capture is re-saved, deleted with the capture, purged when the setting is turned off |
| Design system | Every icon name resolves to embedded Phosphor SVG; icons are template vectors; no accent, palette, gradient, or annotation color is purple; the app icon is 1024 px with transparent corners and a blue tile; the menu bar image is a template |

No real model turn, login, or logout was run against Codex or Claude Code. CLI flags were checked against `codex app-server --help` (codex-cli 0.169.0), `codex features list`, the generated app-server JSON schema, and `claude --help` (2.1.325).

## Renders

`scripts/preview.sh` rendered **138 PNGs** (69 scenes in dark and light) to `docs/previews/`. Reviewed: editor (default, compact, solid, plain, smart tools, backdrop presets, export options), Ask (editor conversation, region attachment, signed out, consent, usage limit, floating panel beside a thumbnail), area-selection bar, thumbnail, pins (default, controls, narrow, locked, opacity), Library (populated, empty), countdown, scrolling, all nine Settings pages (wide, narrow, minimum size, Reduce Transparency, permission and Assistant account states), and Welcome. Stale 0.0.1 contact sheets were removed.

Offscreen renders use the opaque fallback for floating glass; live Liquid Glass is not shown.
