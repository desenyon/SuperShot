# SuperShot 0.2.0 release verification

Version 0.2.0, build 9, targets Apple Silicon and macOS 26 or newer. The detailed [feature audit](2026-11-21-glass-audit.md) covers the underlying capture, editing, recording, and Settings changes.

## Public Ask configuration

Release builds offer ChatGPT through the local Codex app-server. A saved Claude preference resolves to Off until the user selects ChatGPT. The Claude subscription transport is compiled only into local debug builds.

OpenAI documents continued use of app-server authentication for existing local apps. Anthropic restricts third-party apps from routing requests through consumer Claude plan credentials. [OpenAI authentication guidance](https://learn.chatgpt.com/docs/app-server#authentication) · [Anthropic authentication guidance](https://code.claude.com/docs/en/legal-and-compliance#authentication-and-credential-use)

## Synthetic editor timings

One comparison used the same 5K fixture with both signed apps. The 0.2.0 prepackaging run was faster than its packaged run, so these samples are diagnostic.

| Operation | 0.1.1 | 0.2.0 |
| --- | ---: | ---: |
| Drag preview at 1,280 px | 40.3 ms | 65.6 ms |
| Idle preview at 2,200 px | 339.7 ms | 277.4 ms |
| Full-resolution render | 2,521.9 ms | 2,259.8 ms |
| Live paint with 40 selected layers | 2.2 ms | 1.3 ms |

The checks run without activating SuperShot. Preview screenshots use the solid fallback for glass. Live window materials, screen capture, cross-display dragging, and physical audio and camera input remain desktop acceptance checks.
